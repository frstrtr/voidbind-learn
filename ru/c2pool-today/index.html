c2pool сегодня

Состояние c2pool на момент выпуска v0.2.12.16 (25 ноября 2026 г.)

c2pool — это переписанная на C++ реализация p2pool, децентрализованного майнинг-пула, созданная для формата шар V36. У него нет оператора пула: майнеры запускают узлы, которые согласуют общую цепочку шар, и каждый блок, найденный узлом, платит майнерам прямо в coinbase (coinbase-транзакции) этого же блока. Исходный код: github.com/frstrtr/c2pool.

Цепи

c2pool собирает по одному бинарнику на каждую родительскую цепь (c2pool-<coin>). Несколько родительских цепей также ведут в той же coinbase объединённый майнинг вспомогательных цепей AuxPoW.

«Работает» (Live) означает, что публичный узел voidbind запускает этот бинарник без демона монеты в тракте обслуживания (serve path). Это не заявление о зрелости для продакшена: в продакшене используются только линии Litecoin и Dash. DigiByte использует свой алгоритм Scrypt как самостоятельная родительская цепь; это не вспомогательная цепь Litecoin.

Monero, словами самого проекта: «Experimental (v37 lane, Path B payouts; c2pool-v37-xmr, can run daemonless; not built by the release workflow): regtest, stagenet and testnet run a pool; mainnet runs only --follow-only and needs --i-understand-mainnet even for that.» (перевод: «Экспериментально (линия v37, выплаты Path B; c2pool-v37-xmr, может работать без демона; не собирается workflow выпуска): в regtest, stagenet и testnet работает пул; в mainnet работает только --follow-only, и даже для этого нужен --i-understand-mainnet».) Режим пула в mainnet отключён в коде. (README, раздел Supported chains)

Без демона монеты

  • Litecoin и Dogecoin. c2pool содержит встроенные облегчённые узлы для обеих цепей. Они синхронизируют заголовки через собственные P2P-сети этих монет, ведут множество UTXO для расчёта комиссий, держат мемпул и сами строят шаблоны блоков. Ни litecoind, ни dogecoind не нужны.
  • Dash. c2pool-dash сам работает по P2P-протоколу Dash и восстанавливает внутри узла детерминированный список мастернод, кворумы LLMQ, ChainLocks и coinbase по DIP-4. Ему не нужны ни dashd, ни учётные данные RPC, ни доступ к кошельку. Блоки, построенные таким образом, были приняты в mainnet Dash. Правила Dash Core 24 встроены начиная с v0.2.11.1, поэтому у пула без демона нет dashd, который пришлось бы обновлять ради этого хардфорка. Узел по-прежнему можно запустить с dashd в качестве резервного варианта.
  • Bitcoin, Bitcoin Cash, DigiByte и BIP-110 на публичных узлах voidbind тоже работают без демона монеты.

Цепочка шар Litecoin

  • С 2026-11-13 00:00:00 UTC каждая шара имеет версию шары 3601: это формат шар V36 с типом шары 3601, введённый через flag day (фиксированную дату активации) в выпуске, а не голосованием. Он изменил правило выплат при объединённом майнинге и позволяет одной шаре нести сразу несколько вспомогательных цепей.
  • В этой цепочке шар участвуют только c2pool v0.2.12.1 и новее. Узлов Python p2pool в ней нет.
  • Реализации на Python p2pool-merged-v36 и p2pool-dash больше не поддерживаются. Все обновления, включая исправления безопасности, выходят только в c2pool.
  • Выплаты идут по PPLNS (оплата за последние N шар) с экспоненциальным затуханием (период полураспада — четверть окна в 8640 шар). Целевой темп — одна шара каждые 15 секунд.

Публичные узлы

Публичные узлы voidbind и их панели (дашборды): ltc.voidbind.com (Litecoin + Dogecoin), dash.voidbind.com, btc.voidbind.com, bch.voidbind.com, dgb.voidbind.com и bip110.voidbind.com. Каждая панель показывает цепочку шар своего узла; любой, кто запускает узел, видит те же данные в своей собственной копии.

Скачать и проверить

  • Пакеты для каждой родительской цепи под Linux x86_64 (.tar.gz), Windows x86_64 (.zip или установщик) и macOS (один универсальный пакет для Apple Silicon и Intel, macOS 26.0 или новее) лежат на странице выпусков.
  • Каждый выпуск содержит файл SHA256SUMS и, начиная с v0.2.7, отделённую подпись SHA256SUMS.asc. Ключ подписи опубликован на github.com/frstrtr.gpg, отпечаток 99556F8DE6AD66057A1A10EC50AB1379285EFE76.
  • Известные проблемы перечислены в KNOWN_ISSUES.md.
