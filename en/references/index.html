“To be implemented: SegWit, Taproot, MimbleWimble”: where these stand in c2pool

ItemStatus in c2pool (Litecoin node, v0.2.12.16)
SegWitDone. The node requires the SegWit soft fork, builds SegWit block templates and pays P2WPKH and P2SH miner addresses.
TaprootPartly. The node requires the Taproot soft fork. A Taproot (P2TR) payout address is not supported on the Litecoin share chain: a V36 share carries a 20-byte payout hash, so such a miner’s payout is redistributed. See Taproot in c2pool today.
MimbleWimble (Litecoin MWEB)Partly. The node carries the MWEB state forward from block to block and builds a valid, empty MWEB extension block. MWEB transactions themselves are not included in its blocks.
